This dataset consists of pairs of mouse C2H2 proteins and their ChIP-seq occupying sites. We use static random negative sampling to balance the positive and negative samples. The complete code to generate this dataset is available [here](https://github.com/ljw20180420/COP/tree/main/AI/dataset).
